# 全景与点云水平 90 度偏差分析

## 结论

当前数据在 3D 查看器中需要把“全景水平校准”设为 `-90°`，点云和全景影像才能在水平方向上贴合。

这说明偏差不是随机配准误差，而是一个稳定的坐标系基准轴差异：查看器相机默认把世界 `+X` 当作 yaw=0 的视线方向，而原始全景投影公式把 pano local `+Y` 当作水平角的正前方。`+X` 与 `+Y` 在水平平面上相差 90 度，因此需要一个固定 yaw offset 来对齐。

## 现象

未做校准时：

- 天花板灯带、墙角、玻璃边缘等线性结构在点云和全景影像中整体错开。
- 错位方向主要发生在水平平面内。
- 垂直方向和尺度没有表现出同等级别的问题。
- 切换不同视角后，偏差仍然呈固定角度特征。

将“全景水平校准”切到 `-90°` 后：

- 点云中的灯带/墙面边缘与全景影像中的对应结构明显贴合。
- 说明主要问题是 yaw 方向常量偏移，而不是点云坐标、相机位置或 roll/pitch 大范围错误。

## 代码原因

### 1. 查看器 Camera 的 yaw=0 方向

`render/camera.py` 中，查看器相机默认定义为：

```python
# yaw=0,pitch=0 -> +X 方向
return np.array([cp * np.cos(y), cp * np.sin(y), np.sin(p)])
```

也就是：

- yaw = 0° 看世界 `+X`
- yaw = 90° 看世界 `+Y`

### 2. 原始全景投影公式的水平角基准

`算法例子/projectToPanoramic.py` 的 `coordinate_to_pixel()` 使用：

```python
tm = np.arctan(-pt[0] / pt[1])
```

并根据 `pt[1] > 0` 判断 front。也就是全景局部系里：

- pano local `+Y` 是水平投影的正前方基准。
- pano local `X/Y` 共同决定全景图的横向像素 `u`。

### 3. 两套前向基准差一个象限

查看器 3D 视角把 `+X` 当作默认前方；原始全景公式把 `+Y` 当作前方。

在水平平面里：

```text
查看器前方: world/camera +X
全景公式前方: pano local +Y
差异: 90°
```

因此点云和全景会出现稳定的 90 度水平相位差。

## 当前修正方式

在 `render/pano_sphere.py` 中给全景采样增加了 `yaw_offset_rad`：

```glsl
u_pix = mod(u_pix + img_w * yaw_offset_rad / (2.0 * PI), img_w);
```

这只改变全景贴图的水平采样位置，不改变：

- 点云坐标
- 相机位置
- 点云投影矩阵
- roll/pitch/yaw 原始位姿解析
- hover picking

右侧 UI 中增加了“全景水平校准”下拉框，当前验证值为：

```text
-90°
```

## 为什么先做 UI 校准，而不是直接写死

虽然当前数据验证 `-90°` 是正确的，但不同采集设备、导出版本或全景图预处理流程可能会使用不同的前向约定。保留 UI 校准有两个好处：

- 方便快速验证 `-90° / 0° / +90° / 180°` 哪个符合当前数据。
- 后续如果接入其他数据集，不需要改 shader 或重新编译。

如果后续确认所有数据都稳定需要 `-90°`，可以把默认值改成 `-90°`，并在 UI 中保留手动调整入口。

## 建议后续处理

短期：

- 将默认“全景水平校准”设为 `-90°`，符合当前数据。
- 保留下拉框，便于人工复核不同 keyframe。

中期：

- 用 3 到 5 个不同位置的 keyframe 验证 `-90°` 是否始终贴合。
- 优先观察天花板灯带、墙角、玻璃门边缘、立柱边缘等结构。

长期：

- 如果所有数据都一致，建议把这个 offset 作为数据集配置项，而不是硬编码在 shader 中。
- 如果不同数据集 offset 不同，可以在 `Dataset` 中增加 `pano_yaw_offset_deg` 字段，从配置文件或 UI 保存。

## 相关文件

- `render/camera.py`: 查看器相机 yaw=0 看世界 `+X`。
- `render/pano_sphere.py`: 全景 shader 复刻 `coordinate_to_pixel()` 并应用 `yaw_offset_rad`。
- `ui/main_window.py`: “全景水平校准”下拉框。
- `算法例子/projectToPanoramic.py`: 原始全景投影公式来源。
